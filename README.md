# 原神，启动！

SPW 的 Windows 整蛊插件。播放歌曲的歌手或专辑艺术家包含 **HOYO-MiX** 时，不显示预告或确认提示，直接按以下顺序跳转：

1. 已安装国服原神：直接运行 `YuanShen.exe`，跳过启动器。
2. 未找到游戏，但装有米哈游启动器：打开启动器的国服原神页面。
3. 两者都未找到：用默认浏览器打开官方[云·原神](https://ys.mihoyo.com/cloud/)。

系统接受启动请求后，立即播放一次内置的增响版“原神启动”音效。启动失败或取消系统授权时不播放；关闭插件或自动启动开关会停止音效。音效独立于 SPW 的歌曲音量，使用系统默认音频设备，不调整系统总音量。

支持大小写、常见连字符及多人合作的艺术家标签。歌曲标题里单独出现 HOYO-MiX 不会触发。同一首歌暂停、恢复、拖动进度或单曲循环不会反复启动；切到其他歌曲后重新播放可以再次触发。检测到国服原神已在运行时跳过启动。

## 安装与设置

在 SPW 的插件管理中导入 `spw-genshin-start-0.1.0.spmod` 并启用。需要支持 Workshop API `0.1.0-dev23` 的 Windows 版 SPW。

默认读取安装记录和常见安装目录。若游戏或启动器被移动、未登记或使用自定义位置，在插件设置中填写国服 `YuanShen.exe` 或米哈游启动器 `launcher.exe` 的完整路径。可通过“听到 HOYO-MiX 就启动”开关停止自动跳转。

原神自身可能要求 Windows UAC 授权；取消授权会停止本次启动。直接启动游戏会跳过更新检查，版本过旧时请自行通过启动器更新。国际服客户端不作为国服游戏启动。

## 构建

安装 JDK 25 后运行：

```powershell
.\gradlew.bat check plugin
```

插件包位于 `build/libs/`。
